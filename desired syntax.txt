ARCHYTASZX SYNTAX — internal cheat sheet (v0.19.4)
==================================================

RUNNING
-------
  archytaszx                     interactive shell (prompt "dir(n): ")
  archytaszx file.azx [ARGS]     run script(s); non-file args are read by arg(k)
  archytaszx -c "LINE" ...       run lines non-interactively (repeatable)
  flags: --dirac | --zx | --both   output mode (dirac default)
         --unicode  --ascii  --seed N  --verbose  --commands [NO -v]

LEXICAL
-------
  statements separated by newline or ;      # comment to end of line
  line ending in \  joins with the next line
  { ... } blocks may span lines; "else" may start a later line

STATEMENTS
----------
  var n, m                      symbolic variables (default type nat)
  var t: real                   types: nat, int, real, complex
  var N = 2^n                   defined variable
  var z = measure|psi>          measure (result: bool for 1 qubit, else bits)
  measure|psi>                  measure without storing
  func f(x) = a^x % N           classical function
  gate U = |x>|y> -> |x>|y xor f(x)>          gate by basis pattern
  gate F = |x>_d -> 1/sqrt(d) sum(y in 0..d){ e^(2*pi*i*x*y/d) |y>_d }
  |psi> = EXPR                  define/overwrite a state
  <phi| = EXPR                  define a bra
  list L = {|psi>, <phi|, z}    list of values
  show(a, |psi>, ...)           print math values; show(|psi>, ascii|unicode|plot)
  print("text")  print(f"z = {z}")   strings / concrete values ({{ }} escapes)
  seed 7                        RNG seed for measurement / rand
  assume EXPR                   add assumption (used in conditions)
  assert EXPR                   error if not true
  for j in 0..n { ... }         0..n excludes n;  0..=n includes n
                                symbolic range: body may only do |s> = ...
  while COND { ... }
  if COND { ... } else if COND { ... } else { ... }
  EXPR                          bare expression (echoed in verbose mode)

KETS / BRAS
-----------
  |name>   <name|              named state / its conjugate transpose
  |5>                          literal, lowest dimension holding 5 (auto-raised as needed) [NO BS : THING]
  |v>_d   <v|_d   |x>_d        fix dimension d (numeral or variable)
  |0>^@n                       n-fold tensor power
  |+> |-> |i> |-i>             built-in states
  |a>|b>                       tensor (juxtaposition)
  <a|b>                        inner product
  |a><b|                       outer product (operator)
  |name>_d = ...               assign with fixed dimension

EXPRESSIONS (loosest -> tightest)
---------------------------------
  or ; and ; not ; == != < <= > >= ; xor ; + - ; @ (tensor) ;
  juxtaposition (apply op / scalar mult / tensor / braket; groups right,
                 so U |x>|y> applies U to both) ;
  * / % ; unary - ; ^ (right assoc) and postfix ^@ (tensor power)

  sum(k in 0..Q){ BODY }       symbolic sum, also 0..=Q-1
  constants: pi  e  i
  functions: sqrt exp abs floor ceil gcd min max bit(x,k) powmod(a,x,N)
             bitlen denom(x,N) known ifelse(c,a,b)
             arg(k[,default])  (k-th CLI arg, from 1)   rand(lo,hi) (inclusive)
  gates:     H X Y Z S T CNOT SWAP (qubit),  I (identity; last in tensor
             absorbs remaining registers),  H^@n,  (H^@n @ I) |psi>

SHELL WORDS
-----------
  :dirac  :zx  :both           output mode
  :verbose_on  :verbose_off    utop-style echo (val x : nat = 3)
  :config [KEY VALUE|save|reset]   image size / color
  history   quit   exit
  :CMD ...                     engine command (see below)

ENGINE COMMANDS (after ':' ; or bare with --commands)
-----------------------------------------------------
  load SRC (or any non-command line)   show [derivation|start|scalable|certificate|@NAME]
  rules [R]   match [R]   apply R [at k | at nI, nJ]
  check [N=V ...] [against T]   normalize   decide [against] [T]   saturate
  prove [against] [T]   induct [on S] [N=V ...] [against T]
  certificate [emit [derivation|induction|proof] | verify [N=V ...] | show]
  translate [back | dissolve S | split S FIRST | join S S | enclose nA, nB [x M]
             | kill S | fuse nA.outI -- nB.inJ]
  name NAME   names   undo   reset   detail   help [CMD]
  @NAME = named diagram (@start, @current built in)

EXAMPLE
-------
  var n, w
  |s> = H^@n |0>^@n
  |psi> = |s> - 2 |w : n><w : n|s>
  |psi> = 2 |s><s|psi> - |psi>
  var z = measure|psi>
  print(f"got {z}")

See examples/*.azx for full programs (grover, deutsch_jozsa, shor, horrible_state).
