ARCHYTASZX DOCUMENTATION
========================

Installation and Configuration

Applies to: ArchytasZX 0.19.x


1. REQUIREMENTS
---------------

  Component     Requirement
  ------------  -------------------------------------------------------------------------
  Python        3.12 or later.
  Required      numpy, sympy (installed automatically).
  Optional      matplotlib, for typeset output and drawn ZX diagrams.
  Optional      Lean 4 (via elan) and Mathlib, to re-check exported proofs.
  Terminal      Any. Inline images need a terminal with the kitty, iTerm2 or sixel image
                protocol; other terminals receive Unicode text.


2. INSTALLING THE PACKAGE
-------------------------

2.1 From PyPI

    pip install archytaszx

The distribution is named ArchytasZX; the package index normalises the name, so archytaszx and
ArchytasZX refer to the same distribution. The importable package is archytaszx.

2.2 With the drawing extra

    pip install 'archytaszx[viz]'

This adds matplotlib. Without it every output style that needs matplotlib (the default
"render" style and the "zxrender" view) falls back to Unicode text; nothing else changes.

2.3 From a source checkout

    git clone https://github.com/Arhip-Dmitriev/ArchytasZX.git
    cd ArchytasZX
    python -m venv .venv
    source .venv/bin/activate
    pip install -e '.[dev]'

The dev extra adds pytest, pytest-xdist, ruff and mypy.

2.4 Verifying the installation

    archytaszx --help
    archytaszx -c 'var n' -c 'show(H^@n |0>^@n)' --unicode

The second command prints

    H^⊗n |0⟩^⊗n = 2^(-n/2) Σ_{x=0}^{2^n - 1} |x⟩

or an equivalent closed form.


3. INSTALLING THE LEAN LIBRARY
------------------------------

The Lean 4 library is bundled inside the package, in the directory lean/ next to the package's
__init__.py. Its location is printed by

    python -c "import archytaszx, os; print(os.path.join(os.path.dirname(archytaszx.__file__), 'lean'))"

In a source checkout it is archytaszx/lean. The library pins its toolchain in lean-toolchain
(Lean 4.35.0) and depends on Mathlib at the matching revision.

To build it once:

    1. Install elan, the Lean toolchain manager.
    2. cd into the lean directory.
    3. lake exe cache get      (downloads prebuilt Mathlib)
    4. lake build

An exported proof is then checked with

    lake env lean /path/to/proof.lean

run from the same directory. From Python, archytaszx.semantics.lean_net.check(source, path)
writes and checks a proof in one call. See LEAN.txt.


4. CONFIGURATION
----------------

4.1 Configuration file

Image settings are read at start-up from

    $XDG_CONFIG_HOME/archytaszx/config.toml

or ~/.config/archytaszx/config.toml when XDG_CONFIG_HOME is unset. The file is TOML with two
keys:

  Key    Type     Default  Meaning
  -----  -------  -------  ----------------------------------------------------------------
  size   number   1        Scale of rendered images; 1 is one terminal cell of text height.
  color  string   "auto"   "auto" follows the terminal; otherwise any matplotlib colour name.

The file is created and changed from the shell with the :config meta-command (SHELL.txt):
":config size 1.5", ":config save", ":config reset". A missing file means the defaults.

4.2 History file

The interactive shell keeps up to 1000 lines of history in ~/.archytaszx_history when standard
input is a terminal.

4.3 Environment variables

  Variable                Effect
  ----------------------  -----------------------------------------------------------------
  XDG_CONFIG_HOME         Directory holding archytaszx/config.toml.
  ARCHYTASZX_IMAGES       Forces the image protocol: kitty, iterm, sixel or none. Without
                          it the protocol is detected from TERM, TERM_PROGRAM,
                          KITTY_WINDOW_ID and LC_TERMINAL, and is "none" when standard
                          output is not a terminal.
  ARCHYTASZX_IMAGE_THEME  dark or light: the background assumed for images. Without it,
                          COLORFGBG is consulted, and the default is dark.
  ARCHYTASZX_IMAGE_FG     Foreground colour of images, overriding the terminal's own.
  NO_COLOR                When set and non-empty, error lines are not coloured.


5. RUNNING THE TEST SUITE
-------------------------

From a source checkout with the dev extra installed:

    python -m pytest -n 8        default tier
    python -m pytest -m slow     fuzz sweeps and oracle differentials
    python -m pytest -m ""       both tiers
    ruff format . && ruff check . && mypy archytaszx

The default tier deselects the tests marked slow. -n 8 runs the tests on eight workers through
pytest-xdist.


6. UNINSTALLING
---------------

    pip uninstall archytaszx

The configuration file and the history file are not removed; delete them by hand if wanted.
