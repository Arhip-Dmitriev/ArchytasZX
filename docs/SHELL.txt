ARCHYTASZX DOCUMENTATION
========================

The archytaszx Command and Shell

Applies to: ArchytasZX 2.0.x
Implementation: archytaszx.repl.shell


1. SYNOPSIS
-----------

    archytaszx [OPTIONS]                       interactive shell
    archytaszx [OPTIONS] FILE ...              run command files
    archytaszx [OPTIONS] -c CMD [-c ...]       run commands given on the command line


2. OPERANDS
-----------

Every positional operand is a file of engine commands. The files are run in the order given,
in one session, after every -c command. When neither a -c option nor a file is given, the
interactive shell starts.


3. OPTIONS
----------

3.1 General

  --help                 Print the usage summary and exit.
  -c CMD, --command CMD  Run CMD as one line. Repeatable; the lines run in order, before any
                         file.
  --unicode              Print Unicode text instead of ASCII.
  --no-concrete-axioms   Rewrite with bound dimensions kept symbolic: the axioms defined only
                         at a concrete dimension never match, and the other axioms match
                         without substituting bound values.

3.2 Views

The view decides how the diagrams engine commands print are shown. Exactly one may be given;
the default is --dirac.

  --dirac,     -dirac      Dirac notation.
  --zx,        -zx         ZX diagrams drawn with matplotlib (same as --zxrender).
  --zxrender,  -zxrender   ZX diagrams drawn with matplotlib; Unicode without an image
                           protocol.
  --zxunicode, -zxunicode  ZX diagrams on a Unicode character grid.
  --zxascii,   -zxascii    ZX diagrams on an ASCII character grid.
  --both,      -both       Dirac notation and the matplotlib ZX drawing.
  --raw,       -raw        Full ZX graph listings, nothing summarised or capped.

3.3 Saving images

  --images DIR        Also save every matplotlib ZX drawing as a PNG in DIR.
  --images_white DIR  As --images, with black drawings on a white background.


4. EXIT STATUS
--------------

  0     Every line ran without error.
  1     At least one line reported an error, or standard output was closed.
  2     Usage error, or a file could not be read (nothing is run in that case).
  130   Interrupted by Ctrl-C outside a running command.

A line that fails reports its error and execution continues with the next line; the status is
determined at the end.


5. THE INTERACTIVE SHELL
------------------------

5.1 Prompt

The prompt is the name of the working directory followed by the number of the next line:

    Архитас(1):

A continuation line is prompted with dots in place of the name.

5.2 Input lines

Each input line is handled as follows, a leading colon being optional:

  - A blank line or a line starting with # does nothing and is not recorded.
  - history lists the lines entered in this session.
  - quit or exit leaves the shell (as does end of input).
  - A shell command (section 6) changes the shell's settings.
  - Any other line is an engine command (ENGINE_COMMANDS.txt).

A line ending in a backslash is joined to the next. A line that is only load, or @NAME =,
opens a block: the lines after it, up to a blank line, are the diagram source.

5.3 History

On a terminal, line editing and history are provided by readline. The history persists across
sessions in ~/.archytaszx_history, at most 1000 lines.

5.4 Errors

Errors are printed as lines beginning with "error:", in red when colour is enabled (standard
output is a terminal and NO_COLOR is not set). After a failed command, the detail command
shows the engine's full error record.


6. SHELL COMMANDS
-----------------

  Command                Effect
  ---------------------  ------------------------------------------------------------------
  dirac                  View Dirac notation.
  zx, zxrender           View ZX diagrams drawn with matplotlib.
  zxunicode              View ZX diagrams on a Unicode grid.
  zxascii                View ZX diagrams on an ASCII grid.
  both                   View Dirac notation and the matplotlib ZX drawing.
  raw                    View full ZX graph listings.
  listing                Toggle the graph listing printed under each ZX drawing.
  config                 Show the image settings and the configuration file path.
  config KEY VALUE       Set an image setting: size (a positive number) or color ("auto" or
                         a matplotlib colour).
  config save            Write the settings to the configuration file.
  config reset           Restore the default settings.
  help [CMD]             List every command, or show one command's usage.


7. COMMAND FILES
----------------

A command file is UTF-8 text with one engine or shell command per line, a leading colon
optional. Files given together share one session: diagrams named by an earlier file are
visible to a later one.

An indented line continues the command above it on a new line, so a diagram spans several
lines under load or @NAME =. Blank and comment lines inside such a block are skipped. A line
ending in a backslash is joined to the next with a space. From
examples/deutsch_jozsa_proof.azx:

    @out_const =
        count n
        repeat n: X(0 -> 1)
        t = Z(0 -> 1) phase{k: -k/d}
        e = Z(1 -> 0) phase{k: k/d}
        scalar d^(-(n+1)/2)

    load
        count n
        repeat n: X(0 -> 1) -> F^4                          # data qudits
        X(0 -> 1) phase{k: -k/d} -> F^3 -> u = X(2 -> 1)    # target, through U_const
        inputs u.in1
        scalar d^(-n/2)

    decide against @out_const
    certificate lean deutsch_jozsa_constant.lean


8. TERMINAL IMAGES
------------------

Drawn diagrams are shown inline in terminals implementing the kitty graphics protocol, the
iTerm2 inline image protocol, or sixel; the protocol is detected from the environment, or
forced with ARCHYTASZX_IMAGES (INSTALL.txt, section 4.3). Where no protocol is available, or
standard output is not a terminal, drawings are replaced by Unicode text. Image size and
colour are set by the configuration file (INSTALL.txt, section 4.1).
