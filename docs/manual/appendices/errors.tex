\chapter{Exceptions}\label{app:errors}

This appendix lists every exception class of the \texttt{archytaszx} package, grouped by the module that defines it. Most modules follow one pattern: a module base class derived from \py!Exception!, a \emph{grammar} subclass for malformed requests (a wrong type, an unknown name, a malformed structure), and a \emph{domain} subclass for well-formed requests outside the mathematical domain of the operation. Every class of \module{archytaszx.rewrite} derives from \py!RewriteError!. The conditions under which each exception is raised are specified with the operations in the chapters on each module; the benchmark suite's exceptions are specified in \cref{ch:bench-pipeline,ch:bench-tools}.
