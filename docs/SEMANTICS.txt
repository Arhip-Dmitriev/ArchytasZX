ARCHYTASZX DOCUMENTATION
========================

Layer D (part 1): Meaning, Contraction and the Oracle

Applies to: ArchytasZX 2.0.x
Package: archytaszx.semantics (modules denote, contract_numeric, contract_symbolic, check,
         interop)

The second part of Layer D, deciding and proving equality, is documented in PROOFS.txt.


1. PURPOSE
----------

This layer fixes what a diagram means, a linear map between tensor products of qudit spaces,
and computes it in two ways: numerically at a concrete assignment of every symbol, and
symbolically with dimensions and multiplicities kept formal.


2. DENOTATION: archytaszx.semantics.denote
------------------------------------------

2.1 Axis convention

A node with m inputs and n outputs denotes a tensor of rank m + n whose axes are its outputs
in order, then its inputs in order; each axis has the length of its port's dimension. A
diagram's boundary follows the same rule: boundary outputs, then boundary inputs. Every
consumer in the engine uses this convention.

2.2 The generators

With omega_d = e^{2 pi i/d}, and F the unitary discrete Fourier transform
F[j][k] = omega_d^{j k} / sqrt(d):

  Z spider, phase vector (alpha_1, ..., alpha_{d-1}), alpha_0 = 0:
      Z_{m->n} = sum_{k=0}^{d-1} e^{i alpha_k} |k>^(x n) <k|^(x m)
      A node without a phase is the all-ones diagonal. With no legs it is the scalar
      sum_k e^{i alpha_k}.

  X spider, the Fourier conjugate of Z:
      X_{m->n} = F^(x n) . Z_{m->n} . (F^dagger)^(x m)

  F (Fourier box):        F[j][k] = omega_d^{j k} / sqrt(d)
  T (triangle):           T[out][in] = 1 if out == 0 or out == in, else 0
  Ti (inverse triangle):  1 if out == in; -1 if out == 0 and in >= 1; else 0
  W node:                 W[0; 0, ..., 0] = 1, and for i in 1..d-1 the entry with input i
                          and exactly one output equal to i (the others 0) is 1; every other
                          entry is 0
  B (binder), S (splitter):
                          the pair (a, b), a < s, b < t, corresponds to k = a*t + b < s*t;
                          B . S = id and S . B = id exactly

The sign of the Fourier exponent and the normalisation 1/sqrt(d) are fixed here and nowhere
else.

2.3 Functions

    denote(node) -> numpy.ndarray          the complex tensor of one concrete node
    resolve_dimension(node) -> int         the node's single concrete leg dimension
    resolve_dim(node) -> Dim               the same, possibly symbolic
    leg_dims(node), leg_dimensions(node)   every leg dimension, outputs then inputs

denote refuses, before allocating anything, a node whose dimensions or phase are not concrete,
whose legs disagree, or whose shape is illegal.


3. NUMERIC CONTRACTION: archytaszx.semantics.contract_numeric
-------------------------------------------------------------

    contract(diagram, *, max_elements=10_000_000) -> ContractionResult

contracts a fully concrete diagram without bang boxes into one tensor. The diagram is first
validated; a hard error or a deferred dimension issue is refused with ContractValidationError.
A non-concrete dimension, phase or scalar is refused with ContractDomainError. Each node is
denoted, each wire identifies two tensor axes, and the network is contracted pairwise,
smallest result first. The exact scalar is multiplied in last.

ContractionResult holds the tensor, the PortRef of each axis (boundary outputs, then inputs)
and the number of output axes. A tensor larger than max_elements entries, whether a node's,
an intermediate or the result, raises ContractSizeError.

Numeric contraction is the oracle of the engine (section 4): it is used to search for
counterexamples and to cross-check derivations at small concrete sizes, never to produce a
result reported as symbolic.


4. THE ORACLE: archytaszx.semantics.check
-----------------------------------------

    instantiate(diagram, assignment) -> Diagram
    score(diagram, assignment, *, max_elements=...) -> ContractionResult
    compare(a, b, assignment, *, mode=EqualityMode.EXACT, tolerance=1e-9, ...)
        -> ComparisonResult
    compare_tensors(a, b, *, mode=EqualityMode.EXACT, tolerance=1e-9) -> ComparisonResult

instantiate substitutes every dimension, phase, scalar and multiplicity symbol: a symbol the
assignment names takes that value; any other symbol takes its value from the diagram's
parameter environment; a symbol neither supplies raises CheckGrammarError. Bang boxes are
expanded at their instantiated multiplicities.

compare instantiates both diagrams at one shared assignment, first checks that their
interfaces correspond (the same numbers of outputs and inputs, the same dimension per axis),
then contracts and compares.

4.1 Equality modes

  EXACT               (the default) equal shapes and entrywise agreement within tolerance,
                      overall scalar included.
  UP_TO_GLOBAL_PHASE  b == lambda * a for some lambda with |lambda| = 1. lambda is recovered
                      from a's largest entry and verified on the whole tensor. A rescaling by a
                      factor of modulus other than 1 is not a match.

  UP_TO_POSITIVE_SCALAR
                      b == lambda * a for some real lambda > 0, recovered the same way.

Mixed operands (a discard on either side) are compared by their doubled diagrams
(ComparisonResult.doubled); there UP_TO_GLOBAL_PHASE is run as EXACT, the two coinciding on
CPMs. denote.denote_mixed and contract_symbolic.contract_mixed_symbolic give a mixed
diagram's CPM numerically and symbolically (MIXED.txt).

UP_TO_GLOBAL_PHASE and UP_TO_POSITIVE_SCALAR are used only when requested. The tolerance is an absolute entrywise bound,
1e-9 by default, and is never loosened implicitly.

ComparisonResult holds the mode, matched, a reason, the largest deviation and the recovered
lambda.

4.2 Limits of the oracle

The oracle compares tensors axis by axis. It cannot establish that axis i of one diagram is
the same leg as axis i of the other; two diagrams whose boundaries are permuted are
indistinguishable to it whenever the tensors happen to agree. It is evidence at the points it
evaluates, not a proof for other values.


5. SYMBOLIC CONTRACTION: archytaszx.semantics.contract_symbolic
---------------------------------------------------------------

    contract_symbolic(diagram, *, max_steps=1024) -> SymbolicTensor

contracts a diagram with every dimension, phase and multiplicity kept formal. A tensor is an
ordered list of axes (SymbolicAxis: port, dimension, index name) and one exact Scalar entry
over the axis indices. Wires become summed indices; every Kronecker delta is a ModDelta; the
scalar simplifier of Layer A (character sums, delta elimination) closes the contraction.

Bang boxes:

  - A node-scope box closed off from the rest contributes its scope's scalar raised to its
    multiplicity.
  - A node-scope box meeting only the boundary, and a port-scope box on Z and X spiders, make
    the rank depend on the multiplicity: the tensor becomes variable-rank, with
    ReplicatedFactor groups (a factor taken once per copy), ReplicatedBlock runs of boundary
    slots laid out copy-major, and SharedIndex sums.
  - A node-scope box meeting no boundary slot, whose every wire to the rest ends at a Z or X
    spider outside every box and every port scope (one such box per spider), contributes
    F(s)^m: F(s) is one copy's contraction with each crossing leg read as the spider's leg at
    the spider's value s (Z: [leg = s]; X: d^(-1/2) w^(s leg) with the leg's sign), and s is
    summed with the spider's other factors; a copy outside the box that pins s evaluates the
    power.
  - A node-scope box meeting boundary slots and, at its other wires, only Z or X spiders
    outside every box and every port scope (bridged) is a ReplicatedFactor group like a
    boundary-only box. Each spider it reaches carries a SharedIndex s, summed around the
    entry and every factor; the group factor is Sum_x inner(t, x) prod_k perleg_k(x_k, s),
    inner the contraction of one copy with its boundary slots (template order) and crossing
    legs (wire order) open, perleg as above. The index s is eliminated when the entry pins
    it: every term of the entry carries [s = v] (v a boundary index or a constant) and either
    simplifies to [s = v] times itself at s = v, or is [s = v] times a part periodic in s mod
    d (deltas mod d, exp(2 pi i P/d) over integer polynomials P) with every group factor
    periodic too; then v replaces s in the entry and the factors. A pin v other than 0 or a
    bare boundary index needs every group factor periodic on either route. A shared index no
    group factor mentions is summed into the entry. When every term of the entry pins every
    shared index to a constant and each group factor at each term's pins is a constant
    multiple lambda of its value at the first term's pins, the shared indices are summed out:
    the entry becomes Sum_k e_k prod_g lambda_kg^m_g over the terms. A boundary index that a
    delta factor of the entry pins is replaced by its pinned value in the group factors when
    they are periodic in it mod the delta's modulus. A bridged box holding a variable-rank part
    raises.
  - A box wired to any other node outside it, two node-scope boxes meeting one spider, a port
    box over two W nodes, and other shapes not listed raise
    SymbolicContractionUnsupportedError.

    tensor.substitute(mapping) -> SymbolicTensor       values pushed into every dimension,
                                                       multiplicity, entry and factor
    tensor.flatten()                                   the fixed-rank tensor once every
                                                       multiplicity is concrete
    tensor.value_at(index) -> Scalar                   one entry, simplified
    tensor.simplify(), tensor.ranges(), tensor.signature(), tensor.rank
    tensor.to_dense(*, max_elements=...)               enumerate every entry (concrete only)

substitute followed by value_at answers a question about a concrete size without expanding the
diagram: the cost does not depend on the size of the value substituted.

The cost of symbolic contraction grows quickly with the number of phased spiders (in a chain
of spiders with symbolic phases, roughly fourfold per spider).

5.1 Symbolic comparison

Both functions are in archytaszx.semantics.check.

    compare_symbolic(left, right, *, mode=EXACT, max_steps=1024, dimension_floors=None)
        -> ComparisonResult
    find_entry_witness(left, right, assignments, *, tolerance=1e-9, ...) -> EntryWitness | None

compare_symbolic simplifies the difference of two symbolic tensors. It has three outcomes:
equal ("entries are exactly equal with d formal"), unequal, and indeterminate, when the
difference still carries an index sum the simplifier could not decide. An indeterminate result
has matched=False and a reason beginning "indeterminate"; it does not mean unequal. Variable-
rank tensors are compared only when their layouts and shared indices agree. Each replicated
factor is first normalised: the product c of its Mul arguments free of the group's template
indices and of every shared index moves into the entry as c^m, m the multiplicity, and both
are simplified. Groups agree when their multiplicities, marks and inner tensors agree and
their factors are syntactically equal or their difference simplifies to zero, template
indices aligned by position; the entries are then compared. Factors that differ leave the
result indeterminate. A difference the simplifier leaves nonzero is also equal when it
vanishes after powers are written through exp, exponentials are split, and every complete set
of residue deltas [x + r] (r = 0 .. m - 1, m concrete) with one coefficient is replaced by that
coefficient.
dimension_floors supplies least values of dimension symbols (for example d >= 3).

find_entry_witness looks for one assignment and one index tuple at which the two entries
differ, trying the given assignments and then the points the difference's deltas pin.


5.2 Path sums: archytaszx.algebra.pathsum and archytaszx.semantics.pathsum_diagram

    from_diagram(diagram) -> PathSum
    reduce(ps) -> PathSum
    canonical(ps) -> Canon | None
    entry_at(ps, values) -> Cyclo
    compare_path_sums(left, right) -> PathSumComparison

Representation. A PathSum denotes E(i) = c sqrt(2)^k [C(i) = 0] Sum_{y in Z_2^m} exp(2 pi i
P(i, y)) over boundary Boolean variables i (outputs then inputs, the Choi form, low binary
place first) and path variables y. P is a multilinear polynomial with coefficients in Q/Z
(turns); each constraint in C is a polynomial over F_2 (an XOR of monomials); c is a Cyclo, an
element of Q(zeta_N) stored as rational coefficients over powers of zeta_N, compared modulo the
cyclotomic polynomial Phi_N at a common N; k is an integer. The module uses Python integers and
Fractions only and never enumerates a sum.

Translation (from_diagram). Every dimension must be a concrete power of two and every
generator Z, X, F, B or S; a W, triangle, discard, symbolic dimension, weighted or irrational
phase, symbolic bang box or non-cyclotomic scalar raises PathSumUnsupported naming it. Bang
boxes of concrete multiplicity are expanded first. A leg of dimension 2^k is k Boolean places.
A Z spider identifies the places of all its legs and adds the multilinear interpolation of its
phase table (Moebius inversion, exact); an X spider adds a fresh place vector y, the phase
Sum_{a+b<k} sign 2^(a+b-k) y_a l_b for each leg l and its table over y, and sqrt(2)^(-kL); F
adds Sum_{a+b<k} 2^(a+b-k) x_a z_b and sqrt(2)^(-k); B and S regroup place vectors (low part,
then high part). Identified boundary places become constraints i_a + i_b = 0.

Rules (reduce), each an identity over Z_2, applied to a fixpoint in the order below, lowest
variable first; each application is recorded in PathSum.trace:

  [Elim]           y in no term: drop y, factor 2.
  [HH] pivot       every term of y has coefficient 1/2, so they are y Q / 2 with Q over F_2,
                   and Q = z + Q' for a path variable z in no other monomial of Q: substitute
                   z := Q' (its Boolean lift, a xor b = a + b - 2ab, terms with integer
                   coefficients dropped), drop y and z, factor 2.
  [omega]          y carries 1/4 (or 3/4) alone and 1/2 elsewhere, y Q / 2: drop y, add -Q/4
                   (+Q/4), multiply by sqrt(2) zeta_8 (sqrt(2) zeta_8^-1).
  [HH] constraint  as [HH] with Q over boundary variables only: keep [Q = 0], drop y, factor 2.

Canonical form. A reduced sum with no path variable is put in canonical form by Gauss-Jordan
elimination of its constraints over F_2 polynomials (eliminate): the variables are taken in
ascending order, a pivot is a variable occurring in some constraint only as a degree-one
monomial, and the pivot is substituted out of every other constraint and row. Each row then
sets its pivot to a polynomial of the free variables; for affine constraints this is the
reduced row echelon form. Each pivot is substituted out of P by its Boolean lift, P is stored
as multilinear coefficients mod 1 over the free variables, and c sqrt(2)^k exp(2 pi i P(0))
becomes one Cyclo. Equal canonical data mean one function: the rows parametrise the support by
the free variables, and P and c give the value at each support point. For affine supports the
converse holds too (the RREF is fixed by the support, the coefficients by Moebius inversion of
the values, the constant by one support point), so every Clifford diagram reduces to a form
complete for equality (the Dehaene-De Moor form of stabilizer maps). A Toffoli-type support
(a pivot set to a product of free variables) is canonical in the same way but not proved
unique, so differing forms there give UNEQUAL only through an evaluated point. A sum with path
variables left (T gates not paired) or a constraint without a pivot has no canonical form.

The rung (decide, PROOFS.txt section 2.1) compares the canonical forms. When they differ it
evaluates both at points that separate them (a support point of each, a point of one support
outside the other, the indicator point of each free monomial) and reports the first index tuple
where the entries differ.


6. SCALABLE-NOTATION CHECKS: archytaszx.semantics.interop
---------------------------------------------------------

    default_samples(*diagrams, limit=12)
    check_round_trip(diagram, samples=None) -> RoundTripReport
    check_sheet_step(step, samples=None) -> SheetCheck
    via_scalable(diagram, operations, samples=None) -> InteropOutcome

check_round_trip translates a diagram to scalable notation and back and checks, at each sample,
that both instantiate to isomorphic diagrams, that strip agrees with bang-box instantiation,
and that the oracle finds both exactly equal. check_sheet_step replays a sheet operation,
validates its result and oracle-compares its two sides. via_scalable runs a list of sheet
operations and checks every step and the round trip.

default_samples gives each multiplicity the values 0, 1, 2, each dimension 2 and 3, and each
phase or scalar symbol two pool values, diagonals first, at most limit assignments. A sample
outside one side's domain is skipped and counted; a report is ok only when at least one sample
was evaluated.
