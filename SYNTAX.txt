ARCHYTASZX SYNTAX -- INTERNAL QUICK MANUAL
==========================================

There are two input layers in one shell:

  Dirac language    .azx scripts and default shell input    repl/lang.py
  Engine commands   lines that start with ':'               repl/commands.py
                    (their diagram sources: repl/parser.py)


RUNNING
-------

  archytaszx                         interactive, prompt "DIR(N): " (e.g. "archytas(1): ",
                                     "home(34): " in the home directory)
  archytaszx FILE.azx [ARGS...]      run a script
      --seed S                       seed for numeric measurement
      --ascii | --unicode            display style (default: mathtext images when the
                                     terminal shows images, else unicode)
      --mode dirac|zx|both           what show and engine commands print
      --output                       output mode (see 2. SHELL-ONLY WORDS)
      --oracle                       scripts and -c only: check every gate that maps basis
                                     states to basis states for reversibility (off by default)
      --echo                         print "azx> LINE" before each output
  archytaszx -c 'show(1+1)'          run one line (-c can repeat)
  archytaszx --commands              every line is an engine command, no ':'

Mathtext images take the terminal's text colour and cell size when the terminal reports them;
ARCHYTASZX_IMAGE_FG=#rrggbb overrides the colour. Matplotlib loads when the shell starts.

Positional values that are not .azx files are script arguments, read with arg(k).


1. DIRAC LANGUAGE
=================

1.1 Lines
---------

  - Statements are split by newline or ';'.
  - '#' starts a comment.
  - A trailing '\' joins the line to the next one.
  - A '{' left open carries on over later lines until it closes.
  - Only 'show' and 'print' print anything: show for mathematical values, print for
    strings and concrete numbers, truth values and measured bits.
  - A bare expression is a statement too; it prints only in output mode.

1.2 Statements
--------------

  var n, m                        symbolic variables, type nat by default
  var t: real                     types: nat, int, real, complex
  var q = 2^n                     defined variable (redefining is allowed)
  var z = measure|psi>            measure, store the outcome, collapse |psi>
  measure|psi>                    measure without storing (named m1, m2, ...)

  func f(x) = a^x % N             scalar function
  gate G = PATTERN -> BODY        linear operator, defined on basis kets
                                  (an oracle is just a gate: |x>|y> -> |x>|y xor f(x)>)

  |psi>_d = EXPR                  assign a ket of dimension d
  <phi|_d = EXPR                  assign a bra (EXPR must be a bra) of dimension d
                                  without _d the dimension is 2

  list L = {|psi>, <phi|, z}      named list
  show(a, b, ...)   show a        show values
  show(..., ascii)                optional last arg picks the style:
                                  plot (mathtext) | unicode | ascii
  print("text", 3, z)             print strings and concrete values, space separated
  seed 7                          reseed the RNG

  if C { ... } else if C { ... } else { ... }
                                  'else' must be on the same line as the '}'
                                  before it
  while C { ... }
  for j in LO..HI { ... }         inclusive range. A symbolic range may only
                                  hold '|s> = ...' steps; the loop is folded.

  assert C                        error if C is false or not known to hold
  assume C                        record C as a fact for later if/assert

1.3 Kets and bras
-----------------

  |0>  |5>          basis ket; its width is the fewest bits that hold the value
  |k : n>           value k in a register of width n
  |a>|b>            tensor of basis kets
  |2>_3  |0>_d      qudit of dimension 3 / d
  |+>  |->          built-in qubit states (|0> +- |1>)/sqrt(2)
  |i>  |-i>         built-in qubit states (|0> +- i|1>)/sqrt(2); a summation index
                    named i still gives the basis ket |i>
  |psi>  <psi|      named state / its conjugate transpose
  <a|b>             inner product (a scalar)
  |a><b|            outer product (an operator)

If every register of a state has the same dimension d, and d is not 2, write
the state as |name>_d everywhere.

1.4 Expressions -- precedence, loosest first
--------------------------------------------

   1  or
   2  and
   3  not
   4  ==  !=  <  <=  >  >=     (does not chain)
   5  xor
   6  +  -
   7  @                        tensor
   8  juxtaposition            apply, scalar multiply, |a>|b>, <a|b>, |a><b|
                               Groups from the RIGHT, so U |x>|y> applies U
                               to both kets.
   9  *  /  %
  10  unary -  +
  11  ^                        right-associative
  12  ^@ (postfix)             tensor power: H^@n, |0>^@n

On operators:

  A B,  AB,  A * B
                  compose; AB works when the name splits into operator names in
                  exactly one way
  A + B           sum
  A @ B           tensor
  A^k             k-fold composition (k a concrete integer >= 0)
  c A             scale

Sums work on states and on scalars:

  sum(y in 0..q-1){ e^(2*pi*i*x*y/q) |y> }

A summed ket gets its register width from the range. A symbolic range must
start at 0.

1.5 Built-ins
-------------

  constants   pi  e  i
  functions   sqrt exp abs floor ceil gcd min max
              bit(x, j)  powmod(a, b, N)  bitlen(x)  denom(x, N)
              known(x)  ifelse(c, a, b)
  special     (concrete integers only)
              rand(LO, HI)
              arg(K), arg(K, DEFAULT)    script arguments; a name argument
                                         becomes a positive integer symbol
  gates       H X Y Z S T CNOT SWAP      on one-qubit registers;
                                         H^@n covers a whole register
  identity    I                          last in a tensor, it covers all
                                         remaining registers: (H^@n @ I)

Reserved names (not usable for your own names):
  - every statement word
  - the keywords xor in and or not else
  - the built-in functions and constants
  - sum
  - the display styles

1.6 Gate patterns
-----------------

  - A pattern is a product of kets, each holding one distinct variable name:
      |x>|y>   or   |x> @ |y>
  - |x>_d accepts only dimension-d registers.
  - The body must be a ket.
  - Output widths default to the input widths, position by position.

1.7 Values
----------

  - A value stays symbolic exactly when its inputs are symbolic.
  - Measuring one qubit gives a bool; measuring more gives Bits. Both act as
    numbers.
  - Measuring a symbolic state gives a symbol plus constraints, shown in a
    'where' block when that symbol is shown. Showing a state prints the state only.

1.8 Example
-----------

  var n, m, N, a
  var q = 2^n
  func f(x) = a^x % N
  gate U_f = |x>|y> -> |x>|y xor f(x)>
  gate QFT  = |x> -> 1/sqrt(q) sum(y in 0..q-1){ e^(2*pi*i*x*y/q) |y> }
  |psi> = (H^@n @ I) |0>^@n @ |0>^@m
  |psi> = (QFT @ I) U_f |psi>
  show(|psi>)

More examples: examples/shor.azx, examples/shors.azx


2. SHELL-ONLY WORDS
===================

  history               numbered list of the lines entered
  quit | exit           leave the shell
  :mode [dirac|zx|both] show or set what show, output mode and engine commands print:
                        Dirac text, the ZX graph listing, or both. A state's ZX form
                        exists when its widths and dimensions are concrete (up to 64
                        basis states).
  :output [on|off]      output mode: utop style, a rule
                          ─( 21:03:11 )─< command 3 >──────────────{ archytas }─
                        above each prompt and the value of the last statement of each
                        line after it:
                          val q : nat = 2^n        val |psi> : ket = ...
                          - : complex = 1/2 + i/2  (a bare expression)
  :CMD ARGS             engine command (section 3)


3. ENGINE COMMANDS (':' PREFIX)
===============================

  - A line whose first word is not a command counts as: load <line>
  - @NAME refers to a stored diagram. @start and @current are built in.

  load SOURCE|@NAME          read a diagram (Dirac, DSL or listing form)
  show [derivation|start|scalable|certificate|@NAME|SOURCE]
                             show a state
  rules [RULE]               rule names, or one rule's details
                             (alias: list-rules)
  match [RULE]               matches in the current diagram
  apply RULE [at INT | at nI, nJ]
                             rewrite at a match
  check [NAME=VALUE ...] [against TARGET]
                             numeric oracle check
  normalize                  normal form
  decide [against] [TARGET]  decide equality
  saturate                   equality saturation, then extract the
                             cheapest diagram
  prove [against] [TARGET]   tactic proof search
  induct [on SYM] [NAME=VALUE ...] [against TARGET]
                             proof by induction on a symbolic n
  certificate [emit [derivation|induction|proof] | verify [NAME=VALUE ...] | show]
                             emit, verify or show a certificate, written as a
                             theorem and its proof (detail gives the raw record)
  translate [back | dissolve S | split S FIRST | join S S |
             enclose nA, nB [x MULT] | kill S | fuse nA.outI -- nB.inJ]
                             scalable notation and sheet steps
  name NAME                  store the current diagram as @NAME
  names                      list stored diagrams
  undo                       undo the last change
  reset                      restart the derivation at the current diagram
  detail                     the last command's full payload
  help [CMD]                 usage

By default check, decide and prove compare start against current. With
'against TARGET' they compare current against TARGET.

3.1 Diagram DSL (a load source)
-------------------------------

Statements are split by ';' or newline. '#' starts a comment.

  dim d [= 3]                         symbolic dimension (optionally bound)
  count n [= 4]                       multiplicity symbol
  let q = 1                           literal value
  a = Z(0 -> 1, d)                    spider: Z or X, inputs -> outputs, dim
  a = Z(0 -> 0, d) phase {1: 1/2}     phase, in turns
  a = X(1 -> 1, d) phase[d] {1: 1/4}
  a = F(in: [d, d], out: [d])         other generators, per-port dimensions
  wire a.out0 -- b.in0, b.out0 -- c.in0
  inputs a.in0
  outputs a.out1, b.out0
  scalar d*n
  box p x n nodes a, b [in outer]     !-box over nodes
  box p x n ports a.out0              !-box over ports

The parser turns concrete numerals into symbols. 'literal N' keeps N concrete.

3.2 Dirac source (a load source)
--------------------------------

The engine-side form:

  sum_{k=0}^{D-1} |k,k,...>
  |k>^{n}

An optional trailing '; copy' is allowed.

Reserved words: plus id copy zero F triangle bind split GHZ Z X W Z_phase

3.3 Listing (a load source)
---------------------------

Whatever ':show' prints in zx mode, read back exactly.
